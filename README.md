# ApexCare Dental Website

A responsive dental clinic landing page recreated from the supplied reference image and expanded with essential production-style sections.

## Included
- Responsive navigation
- Hero section with appointment CTA
- Trust/about section
- Dental services
- Why choose us / benefits
- Patient testimonials
- Appointment request form with client-side feedback
- Contact information
- Responsive footer
- Mobile navigation
- Modern typography and responsive layout

## Run
Open `index.html` in a browser.

The demo uses Unsplash image URLs for the dentist photography. Replace them with your own optimized images before deployment.
